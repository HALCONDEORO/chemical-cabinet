# Project page

`docs/index.html` is a single static page with no JavaScript, no third-party fonts, no analytics and no cookies. Styles are in `docs/site/styles.css`.

Preview: `python -m http.server -d docs 8000`, then open `http://localhost:8000`.

Publish: repository Settings, Pages, deploy from branch `main`, folder `/docs`. The expected address is `https://halcondeoro.github.io/chemical-cabinet/`; check it loads before linking to it.
