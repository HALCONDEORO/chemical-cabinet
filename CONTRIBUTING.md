# Contributing

- Open an issue or a pull request. Keep changes small and focused.
- Write code, comments, issues and pull requests in English.
- No new dependencies without a clear reason in the pull request. The app runs on the Python standard library only.
- Add or update tests for behavior changes: `python -m unittest discover -s tests -v`.
- Use invented demo data only. Never commit real inventories, photos, safety data sheets of a real site, names or addresses.
- The app is a tracking aid. Do not add features that recommend mixing or storing chemicals, or that claim legal compliance.
- If you used an AI assistant, say so in the pull request and read the full diff yourself before submitting.
